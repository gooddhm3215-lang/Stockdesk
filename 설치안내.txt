종목 분석 데스크 - 안드로이드 APK 만들기 (GitHub 자동 빌드)
========================================================

PC에서 1~4번을 한 번만 하면, GitHub 서버가 APK 파일을 자동으로 만들어 줍니다.
비용은 들지 않습니다. 이 폴더에는 API 키 같은 개인정보가 들어 있지 않습니다.

1. GitHub 계정 만들기
   https://github.com 에서 가입하고 로그인합니다.

2. 저장소 만들기
   오른쪽 위 [+] → [New repository]
   - Repository name: StockDesk
   - Public 선택 (폰에서 로그인 없이 APK를 받기 쉬움)
   - [Create repository]

3. 파일 올리기
   생성된 화면에서 "uploading an existing file" 링크를 누릅니다.
   이 폴더(StockDesk-Android) 안의 파일과 폴더를 전부 선택해 브라우저 창으로 끌어다 놓습니다.
   - .github 폴더가 꼭 같이 올라가야 합니다. (APK 자동 생성 설정이 들어 있음)
   - 이 안내 파일은 같이 올라가도 상관없습니다.
   아래 [Commit changes]를 누릅니다.

4. APK 생성 확인
   저장소 위쪽 [Actions] 탭 → "APK 만들기"가 돌아가는지 봅니다. (5~8분)
   - 초록색 체크: 성공
   - 빨간색 X: 실패. 눌러서 빨간 줄의 오류 메시지를 Claude에게 보여 주세요.

5. 폰에 설치
   폰 브라우저에서 https://github.com/본인아이디/StockDesk/releases 를 엽니다.
   맨 위 릴리스의 Assets → StockDesk.apk 를 눌러 내려받고 설치합니다.
   - "출처를 알 수 없는 앱" 경고가 나오면 [설정] → 이 브라우저 [허용] → 다시 설치
   - Play 프로텍트 경고가 나오면 [무시하고 설치] (직접 만든 앱이라 나오는 경고)

6. 앱 첫 설정
   앱 오른쪽 위 [설정]에 Claude API 키를 넣습니다. (발급: https://console.anthropic.com)

■ 앱을 고친 버전이 오면
   GitHub 저장소에 바뀐 파일을 다시 올리면 새 APK가 자동으로 만들어집니다.
   폰에서 새 APK를 설치하면 기존 앱 위에 업데이트됩니다. (설정은 유지)
